# 難易度制約と厳密数値答案

## 目的

難易度選択を表示上のラベルで終わらせず、生成可能な問題ファミリーと数値追問の条件に反映する。最終数値答案に循環小数・近似小数を採用しない。

## 難易度の割り当て

| 難易度 | 生成対象 | 実際に制御する要素 |
|---|---|---|
| 3 | 2014/2015型 | 基礎的な証明と整数・簡潔な厳密値 |
| 4 | 2016型 | 平行四辺形などを含む中段階の証明と計算 |
| 5 | 2017/2024/2025/2026型 | 複数条件の証明・標準的な数値追問 |
| 6 | 2017型 | `AD+AE` の厳密値 `2+√3` |
| 7 | 2017型 | `AD+2AE` の厳密値 `(3+2√3)/3` |
| 8 | 2017型 | `(7+4√(AD²+16AE²))/23` の厳密値 `(7+4√13)/23` |

難易度6〜8では既存の2017型幾何条件を崩さず、尺度と数値追問を調整する。別の角度や点配置を無理に入れて証明条件を壊さない。

## 数値答案のポリシー

- 整数・既約分数・平方根を含む厳密値を優先。
- 難易度8は分子が `a+b√c` の分数形式。
- 答案を有限の許容表現にできないときは小数に丸めず、生成を拒否。
- 中間的な補助線分値も近似小数として保存しない。
- 代数式の照合は登録済みの有限な係数・根号候補に対して行う。これは汎用CASや任意の代数的数の完全判定ではない。

## 検証

`tests/theorem-foundation/difficulty-and-exact-numeric.test.js` は難易度3〜8の生成対象、数値答案形式、難易度8の分数形式、数学検証バッジの非表示を確認する。


- 生成条件に合う問題テンプレートがない場合は、画面内モーダルで原因と対処を案内する。
- 難易度8は、線分値から `√(AD²+16AE²)` を計算し、`(7+4√13)/23` 型の厳密分数へ到達する。小数近似は使わない。

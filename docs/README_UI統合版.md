# 入試対策証明ジェネレーター — UI統合版

## 起動方法（macOS）
1. ZIPを展開します。
2. `start.command` を実行します。ブラウザでローカルページが開きます。
3. 実行できない場合は、ターミナルでこのフォルダに移動し、`python3 -m http.server 8000` を実行して `http://127.0.0.1:8000/` を開いてください。

## UI
- 作成：証明形式・難易度・詳細条件を指定して問題を生成
- 復習：収録済み年度の過去問をランダム表示
- HINT：現在の問題の証明方法と条件を使ったヒント
- 設定：クレジット表示
- SAVE：ブラウザ保存、JSON書き出し・読み込み・削除
- ANSWER：証明ステップと追問の答えの表示切替
- PDF：問題と解答を印刷ダイアログからPDF保存

問題生成はルールベースです。独立幾何検証と証明構造監査を組み込んでいます。証明監査で未証明と判定された箇所は、数学的に誤りと断定せず、現行ルールでは未証明として扱います。


## 表示修正
問題生成後に問題画面が非表示のままになる CSS の指定を修正しました。`problem-view` から `hidden` が外れたときに画面が表示されます。

## 追加修復（解答・HINT・年度別生成）

- `criterion-badge` は表示幅を監視し、文字幅に合わせてフォントサイズを自動調整します。
- `ANSWER` は解答パネルを開閉します。証明ステップ・証明基準・追問の計算過程と答えは `js/answer_generator.js` がデータ構造を正規化して構成します。外部LLMは使用しません。
- `HINT` はアプリ独自のモーダルで表示します。背景クリック、閉じるボタン、Escapeキーで閉じられます。
- 2014・2015・2016・2017・2024・2025・2026年度の全7テンプレートで、条件に沿った類題生成と解答構成を確認しています。
- 2014年度型の角度パラメータは、図形条件を満たす組から選択するようにし、不成立な角度構成を除外しました。
- テスト: 既存6件、既存ES module 18件、新規解答7件、全年度生成1件。


## 次段階：答案入力とフィードバック

- 問題画面下部の「自分の証明を書く」に答案を入力し、「証明を確認」で登録済みの年度別チェック基準と照合できます。
- 不足している証明要素を表示し、結論だけの答案を正解扱いしないようにしています。
- 対象は2014・2015・2016・2017・2024・2025・2026年度型です。
- この判定は登録済みパターンの照合であり、自由記述の数学的正しさを完全に保証するものではありません。別解や表現差による誤判定の可能性を画面上にも明記しています。
- 詳細は `README_次段階_答案入力とフィードバック.md` を参照してください。

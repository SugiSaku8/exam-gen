# 2024〜2026年型の制約ベース図形再構成

`js/templates/recent_geometry_builder.js` は、過去問の座標を回転・拡大する代わりに、幾何条件から各点を再計算します。座標は描画用の単位円に正規化し、実際の半径・弧長は問題文の条件として別に保持します。

## 2024年型

- A、B、Cを円周上に配置
- AB=ADとなるよう、DをAC上に構成
- BDと円の第2交点としてEを計算
- P1はAEとACの垂直二等分線の交点（PA=PC）
- P2はAEと直径ECの円との交点（∠EPC=90°）
- F1、F2をCPとBEの交点としてそれぞれ再計算
- 生成した配置から弧の比、∠CFD、∠ABEを再計算し、条件と答えを同時に更新

## 2025年型

- A、B、C、Dを円周上に構成し、CA=CDを満たすDを選択
- E=AC∩BD
- FはABと、Eを通りBCに平行な直線との交点
- G1はBD上でBG=BAとなる点、P1はAGと円の第2交点
- P2はAの対蹠点、G2=AP2∩BD
- 半径と中心角から弧DPの長さを厳密なπ式にして更新

## 2026年型

- AB=ACを満たすようにB、CをAに関して対称な中心角に配置
- AC∥BDを満たすDを円周上に構成
- P1は∠PCA=∠BCDを満たす中心角から計算
- P2はCの対蹠点（CP2が直径）
- E=AB∩CD、F1/F2=AB∩CP1/CP2
- 弧BCの長さ、中心角、∠DPCの答えを連動して更新

各生成物には制約チェック結果が `validation.geometry.checks` として保存されます。さらに `js/geometry_validator.js` が生成器のチェック結果を参照せず、保存された座標から独立して条件・証明目標・数値答案を再計算し、`validation.independent_geometry_audit` に記録します。

# 次段階：証明難易度エンジン

## 追加したもの

- `js/difficulty_engine.js` に、生成後の実データから難易度契約を監査する処理を追加。
- 自動生成時は難易度ごとの年度ファミリーを再確認し、違う年度の問題が紛れたら生成を失敗させる。
- 各年度の元証明について最低ステップ数を確認し、証明文が欠落・短縮された問題を受け入れない。
- 証明の段階数、形式証明の依存深度、使用推論規則の種類、必要条件数、依存辺数、図形の点数を計測する。
- 難易度6は平方根を含む厳密値、難易度7・8は分子が `a+b√c` の分数を要求する。小数答案は拒否する。
- 問題画面に難易度の内訳を表示する。数値だけでなく、証明側と計算側を分けて示す。
- 「数学検証済」バッジは追加していない。既存の内部検証は引き続き動作する。

## 難易度ファミリー

| レベル | 対象年度・型 | 主な制約 |
|---|---|---|
| 3 | 2014・2015 | 基礎的な証明構造 |
| 4 | 2016 | 平行四辺形などを介した複数段階の推論 |
| 5 | 2017・2024・2025・2026 | 条件をつなぐ証明・標準的な厳密計算 |
| 6 | 2017型 | 平方根を含む厳密値 |
| 7 | 2017型 | `(a+b√c)/d` 型の厳密値 |
| 8 | 2017型 | 分子が `a+b√c` の最難関分数形式 |

## 判定の意味と限界

難易度は登録済みテンプレートと答案形式に対して校正した値です。証明ステップ数・依存深度・定理種類数は再現可能な指標ですが、あらゆる生徒にとっての絶対的な難しさを数学的に決定するものではありません。また、レベル6〜8では証明の構成は同じ2017型を保ち、主に数値計算の難しさを上げています。証明そのものを別の段階まで難しくしたと誤認させないため、画面では証明と計算の内訳を分けて表示します。
